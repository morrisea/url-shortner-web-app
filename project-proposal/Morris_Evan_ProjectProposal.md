## Project Description
The URL (Uniform Resource Locator)  shortener website will allow users to be able to create and store shortened URLs. The main functionality of the website will store, hash, 
and return shortened URLs to the user that will send a 302 HTTP response to redirect to the appropriate website when calling the endpoint. The primary purpose of this application is to provide an 
easier, terse way to manage URLs.
